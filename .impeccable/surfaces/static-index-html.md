# 排班主页视觉契约

## 目标

把首页处理成“值班室里的手写排班册”：顶栏、侧栏、统计和备忘录具有纸张、墨线、标记笔与便利贴质感，同时保留 31 天排班表的规则几何与快速扫描能力。

## 首屏叙事

1. 顶栏先确认系统、月份与同步状态。
2. “当天排班”和“导入排休”作为持续可见的主要动作。
3. 主排班表占据最大面积并保持粘性表头、姓名列与水平滚动。
4. 统计和备忘录作为侧栏纸卡；窄屏时移动至主表下方。

## 页面专属约束

- 顶栏、主表、弹窗、表单和右键菜单保持 0°。
- 静态便签最多使用四组固定微旋转；桌面最多三条胶带、两个图钉，移动端最多一条胶带。
- 波浪下划线只用于标题。
- 除 `.schedule-wrap` 外不得出现页面级横向溢出。
- 不改变 `/api/*`、既有 DOM ID、inline handler 或排班交互契约。
